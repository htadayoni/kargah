# Reporting security issues

Please do not post credentials, exploits affecting users, or sensitive vulnerability details in public issues. When the repository is public and private vulnerability reporting is enabled, use GitHub's private security advisory reporting feature. Until a private reporting channel has been configured by the maintainers, do not disclose sensitive details in a public issue.

Include the affected version, a minimal reproduction, the expected impact and mitigation if known. Never include another user's private data.
