# Kargah

Kargah is a browser new-tab workspace for builders and solo founders. The extension is in [`extention/`](extention/README.md) and uses React, TypeScript and WXT.

## Development

```sh
cd extention
npm ci
npm run dev
```

For build and manual installation instructions, see the [extension README](extention/README.md). To create a widget, read the [widget contribution guide](extention/docs/widget-contributions.md). For pull requests, see [CONTRIBUTING.md](CONTRIBUTING.md).

## Project status

Funding Radar currently contains fictional example data and is available only in developer mode. Widget contributions are bundled into the extension after review; third-party code is not sandboxed or dynamically installed.
